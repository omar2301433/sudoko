# Sudoku Game in C++

## Overview
This project is a console-based Sudoku game written in C++.  
It includes:

- Sudoku board generation
- Sudoku solving using Backtracking
- Multiple difficulty levels
- User input handling
- Automated test cases using `assert`

The game generates a complete Sudoku board, removes numbers according to the selected difficulty, and allows the player to solve the puzzle interactively.

---

# Features

- Random Sudoku board generation
- Sudoku solver using recursion & backtracking
- Easy / Medium / Hard difficulty levels
- Input validation
- Console-based gameplay
- Automated unit tests

---

# Technologies Used

- C++
- Standard Library (`iostream`, `ctime`, `cassert`)
