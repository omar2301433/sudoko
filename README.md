# Sudoku Game

A full-stack console-based Sudoku Game built using C++.  
The game allows users to generate and solve Sudoku puzzles with different difficulty levels using a backtracking algorithm.

---

# Features

- Generate random Sudoku boards
- Solve Sudoku using Backtracking Algorithm
- Multiple difficulty levels
  - Easy
  - Medium
  - Hard
- User input validation
- Interactive console gameplay
- Automated test cases using `assert`
- Sudoku board display system

---

## Libraries Used
- iostream
- ctime
- cassert
